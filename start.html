再把任务放进来。

在浏览器创建、修订和交接。本机 Python 负责真实生成与核对，原型、PRD、Word 来自同一份任务材料。

已公开的本地工作台基线：d54e658（2026-10-28）。首次试用可按下方任务卡走完一轮。没有在线托管演示。

01 / CHECK YOUR COMPUTER

先确认这台电脑适合运行

  • 当前实际验证：macOS + Chrome。需要 Python 3.10+、网络安装 Word 依赖。
  • 本地服务器依赖 Unix 的 fcntl；Windows 当前不支持，Linux 首次安装和其他浏览器未验收。
  • 先解压完整副本，在工具包根目录打开终端。工作目录放在源码外并完整备份。

若环境不符，可先在首页浏览预制案例或查看完整演示；不需要填写真实公司材料。

02 / RUN THREE COMMANDS

复制三行命令，保持终端运行

python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python pm_workbench.py --workspace ../my-pm-workspace --port 8841

启动成功后，终端会显示本机地址，例如 http://127.0.0.1:8841。将它复制到 Chrome 地址栏。此静态页面不会替你启动服务。

端口被占用时换一个端口，并使用终端显示的地址。保持终端运行，停止时按 Ctrl+C；重新运行相同命令可恢复项目。一个工作目录只能由一个服务写入，勿改成公网或局域网监听。

03 / CREATE → REVISE → HANDOFF

第一次，先走完一个合成任务

  1. 按试用卡导入 trial/TASK-INPUT.json，保存并生成首版。
  2. 将筛选位置由侧栏改到顶部，准备真实差异，逐条处理反馈。
  3. 打开真实原型，执行三项检查并记录观察，生成和下载交接包。
  4. 重新启动后恢复项目，检查修改、版本和文件是否仍在。
