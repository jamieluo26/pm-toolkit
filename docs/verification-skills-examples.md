# Skills与案例：本轮验证与限制

2026-11-02。以下描述分发内容的本地验证层次，仓库发布与远端验收由维护控制记录单独核对。

## 本次准确供料

六个案例分别以完整、同字节的Skill入口与新编合成材料显式供料。输入由Codex编写，不对应真实人员、会议、审批或生产；各例独立，不拼成同一项目的真实履历。

本轮最终六次调用使用已安装的桌面版Codex CLI `0.166.0-alpha.5.1`，请求模型`gpt-6.1-sol`及medium推理；六次均成功完成，没有完成的工具调用。它们验证文字供料，不验证原生安装、自动发现或全宿主兼容。此前终端CLI `0.147.0`因模型不兼容失败，旧失败记录保留在维护控制区，不包装为成功。

每个案例的`run.json`列出准确输入、完整Skill树、prompt及输出SHA256。`result.md`逐字符对应本轮最终调用的最后agent_message，没有润色。案例README和首页的编辑解读由Codex整理，尚未被当作真人认可。输出中即使出现“人工判断”等措辞，也只是AI草案的拟供核对内容。
