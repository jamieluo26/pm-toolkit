# 本地环境检查与 HTML 静态审计

这两项支撑工具帮助准备本地运行和交接材料。它们只读取明确范围，不安装依赖、不修改宿主、不调用模型，也不执行 HTML 页面。

## 先检查运行准备情况

在工具包目录中运行：

```sh
python3 pm_doctor.py
```

需要检查另一份明确的工具包副本时：

```sh
python3 pm_doctor.py --root ../another-toolkit-copy
```

工具报告：

- 当前 Python 是否达到 3.10。
- `python-docx` 的已安装分发元数据是否匹配 `1.2.0`，以及模块能否被找到；不会导入第三方代码或实际渲染 Word。
- 四个固定上游分发文件是否与本地 `UPSTREAM.json` 的 SHA-256 一致。
- 六份 Markdown 模板、任务 JSON 模板、两类原型模板，以及六个核心 Skill 的 `SKILL.md` 是否为可读非空普通文件。

退出码 `0` 表示这些声明的本地条件齐备；`3` 表示存在需要处理的缺失、版本不符、空文件或来源文件差异；`2` 表示根目录或声明结构不符合输入合同。结果在标准输出中为 JSON，不输出被选根目录的绝对路径。

集合与表单生成只需标准库；即使它们可以运行，缺少 Word 依赖仍会使完整工具包检查返回 `3`。按你需要的任务选择对应条件，不要为通过检查盲目更改环境。安装命令见工具包运行说明，doctor 本身不执行安装。

文件存在不代表 Skill 已安装、治理通过或所有宿主兼容。与本地清单哈希相同也不构成来源签名、许可或远端真实性证明。首次使用、模型调用、浏览器与 Word 排版验收仍需各自证据。

## 给定 HTML 文件的静态审计

先选定要交付或检查的 HTML 文件，再逐个显式传入：

```sh
python3 tools/html_static_audit.py --input index.html
python3 tools/html_static_audit.py --input examples/personal-tasks/output/prototype.html --input examples/request-flow/output/prototype.html
```

工具每次接收 1–32 个 `.html` / `.htm` UTF-8 普通文件。单个文件最多 2 MiB，总共最多 16 MiB，单文件最多 30,000 个元素；拒绝符号链接、符号链接父目录、超大文件和重复选择。它不会扩展成目录扫描，也不会读取页面所引用的 JS、CSS、图片或其他文件。

输出包括：

| 观察 | 具体含义 |
|---|---|
| 重复 ID、空 ID | 按给定 HTML 源码中的字面属性统计，保留出现行列 |
| 同文件 `#fragment` | 对照源码中出现的 ID 或旧式命名锚点；有 `base href` 时标记为解析未知 |
| 脚本 | 元素数量、类型类别、是否有 `src`；不会运行脚本 |
| 外部 URL | `href/src/action/formaction` 的外部引用数量、位置与协议类别；外链本身不被判为漏洞 |
| 表单方法 | `get/post/dialog`、默认方法及 `formmethod` 覆盖的字面情况 |
| 文件与选定目录摘要 | 输入序号、字节、SHA-256，以及仅这批被选文件的清单摘要 |

输出不回显输入路径、ID 文字、URL 文字、表单地址或页面正文。定位使用“第几个输入、行列、值的 SHA-256”；需要查看具体内容时，在自己的本地文件中按行列检查。目录摘要只描述所选文件，不证明目录已全量扫描。

退出码 `0` 表示有限静态检查未发现上述需复核项；`3` 表示重复/空 ID、缺失或因 `base` 无法判定的局部锚点、非法方法、重复属性、活动协议或无法解析的 URL 等需复核；`2` 表示输入合同错误。脚本或普通外链的存在本身不使结果失败。

检查结果不是完整 HTML 标准校验，也不是安全认证。源码中的锚点存在不证明它在运行态可见、可点或含义正确。点击行为、动态 DOM、控制台、排版和业务验收需要真实浏览器及人工观察。给定结果可以作为交付证据的一部分，不能代替整个验收结论。

## 保留证据

需要留存报告时，由调用者将标准输出保存到自己的新文件。工具不会选择输出位置，也不会修改被检查的输入：

```sh
python3 tools/html_static_audit.py --input index.html > ../index-static-report.json
```

记录命令的退出码、所用工具版本和报告对应的文件 SHA。重新生成或修改 HTML 后重新审计；不要将旧报告当作新版本证据。Shell 的 `>` 会覆盖同名文件，保存前请选定新的报告文件名。
