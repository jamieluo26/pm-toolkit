# 验证范围

本页描述首版需要并已在本地记录的验证层。当前准确树、环境和证据另以随首版冻结的发布清单与本地回执绑定；不能沿用旧组件结果冒充本轮组合已验证。

| 层 | 方法 | 能支持什么 |
|---|---|---|
| 输入与输出 | init/demo/build/check及异常反例 | 有限接口、同源投影、错误与不覆盖行为 |
| 内容一致 | 对当前新DOCX做完整有序回读 | 新模型与实际文档有序正文一致 |
| 示例原型 | 当前Chrome默认、重复主题、空态、返回全部 | 给定四本合成书目的几个有限场景 |
| 导图与入口 | 本地首页、案例、图、下载入口实点 | 相应版本入口和当前场景呈现 |
| 文档排版 | 新DOCX用独立排版器渲染，逐页目视 | 当前页的可读性，不保证所有Office字体环境 |

预制案例的manifest仍把browser_behavior、visual_layout与human_acceptance写成NOT_RUN，因为通用build命令不执行这些步骤。本次制作时另外完成的UI/排版检查是该准确版本的外部证据，不会被写成使用者每次运行都通过。

没有真实用户采用、效率提升、业务验收、模型调用、多人协作、生产上线或完整60组件集成声明。支持的最低Python版本为语法要求；本轮只验证回执列明的实际环境。
