# 可选工具与历史案例

主要交付是[Skills与案例](../README.md)。需要进一步演示产品表达或生成文件时，可以使用以下既有工具；它们不是文字Skill的前置条件，也不会让Skill草案自动落实。

| 想做什么 | 入口 | 范围 |
|---|---|---|
| 浏览旧版工具包演示 | [原首页演示](../toolkit-demo.html) | 原页面完整保留；其中工作台路径是工具使用流程 |
| 本地创建、修订与交接 | [本地工作台说明](local-workbench.md) | 按其Python依赖、桌面环境与输入合同操作 |
| 看一轮同源原型/PRD/Word | [阅读工具完整案例](../examples/lifecycle/README.md) | 合成材料与实际代理操作，不能当真人业务结果 |
| 讨论有限表单 | [表单说明](form-cli.md) | 单表单与会话状态，不是真实审批后台 |
| 定制集合原型 | [集合说明](prototype-loop.md) | 给定字段、数据与有限交互 |
| 使用配套模块 | [能力地图](../MODULES.md) | 按各模块自己的合同与依赖使用 |

开发中的独立PM工作室未包含在本轮公开基线，不能从此页推定已发布。已有工具的运行、Word内容/版式及浏览器观察，仍按其独立验证记录说明；这些检查不阻止单独使用文字Skill。
