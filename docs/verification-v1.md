## 代理试用发现与复验

代理首次使用“个人周末器材借用请求”这一新合成场景。先保留未决天数规则，build/check返回HOLD；给出仅用于练习的范围声明后生成首版。再用公开修订准备步骤处理两条采纳与一条拒绝反馈，保留未决评审HOLD并完成新版本，无需手填哈希。

首轮8条实际浏览器条件中7通过、1失败：输入8超过给定上限7时能阻止提交并保留输入，但错误没有直接指出上限。修复使用各字段声明的实际minimum/maximum生成提示，没有硬编码练习数值。准确运行时代码的28项纯函数检查及139项回归通过；新冻结ZIP再执行原输入与原预期，8条全部通过。旧失败与旧HOLD交付保留，未将旧PASS改绑成新版观察。

| 实际条件 | 复验结果 |
|---|---|
| 清空必填后提交 | 阻止转换，保留草稿及其他输入 |
| 数值超过声明上限 | 明确显示上限并保留输入 |
| 可选数值留空、恢复样例 | 允许提交；恢复源初值 |
| 有效输入提交 | 已提交，业务字段只读 |
| 退回缺理由 | 阻止退回并显示理由错误 |
| 带理由退回、编辑并重提 | 可编辑后再次转为只读并保留改动 |
| 完成 | 终态只读，无后续业务动作 |
| 完成后刷新 | 恢复源草稿与原样例 |

review、build/check、deliver/deliver-check通过。交付的SUPPLIED_EVIDENCE_COVERED只汇总给定观察；实际执行证据由代理另存。手册保留需求声明、排除项与给定决定，复盘不虚构业务收益。

代理新Word的114项有序内容核对通过。其附加渲染器首轮5页中文缺字，视觉仍记环境HOLD；随后由制作者对同字节DOCX使用本机已有中文字体作隔离补证，6页逐页可读，无裁切或遮挡。这个补证是额外环境支持，不称为代理无帮助自行视觉通过，也不修改DOCX或分发字体。公开[FAQ](faq.md#中文-word-显示方框怎么办)与[维护说明](maintenance.md)提供字体和阅读条件说明。
