# 支持范围：公开基线与本地工作台候选

2026-10-28。当前公开基线为 `92919fbe1a878677de91c2ab809e7b1faf2468b9`，344 文件：保留 v1.0 核心及旧工作台交互原型。本地运行候选新增真实 Python 接线，尚未发布到 GitHub；没有在线托管或桌面安装包。

## 按任务看能力

| 能力 | 已公开基线 | 本地工作台候选 |
|---|---|---|
| 需求与范围 | 六工作包、任务输入合同、来源与待定项 | 可视化填写背景、范围、规则和检查，保存到本机项目 |
| 原型类型 | 有限集合；本地单表单与有限状态流 | 复用两类核心，字段限文本/数值/单选/标签 |
| 原型、PRD 与 Word | 通过本地 Python CLI 单向生成；旧操作原型不调用 CLI | 界面调用真实 `build/check`，下载同版原型、PRD 和 DOCX |
| 修改和版本 | CLI 绑定前后输入并核对；旧原型只比较浏览器草案 | 冻结前后版，准备准确变化路径，提交反馈处理并生成修订 |
| 检查与交接 | 汇总给定观察；未执行或错版保持待补充 | 逐条提交观察，保留失败/复验，实际 `deliver/deliver-check` |
| AI 辅助 | 六项文字 Skill 的准确树与指定宿主显式供料已验证 | 不调用模型、不安装 Skill、不修改宿主或 Skill 内容 |
| 保存 | CLI 使用新目录；旧交互原型显式保存浏览器草案 | 工作目录持久化项目；每次运行保留独立制品；支持草案文件导入导出 |

本地入口见[启动说明](local-workbench.md)，旧原型见[设计记录](workbench-prototype.md)。

## 保存与材料处理

工作台只监听 `127.0.0.1`，限制准确 Host、同源请求和写入会话令牌；生成页面在隔离预览框架打开。此设计不是多人服务，不能把地址暴露到局域网或公网。项目目录放在仓库外；导出包会保留调用者内容，本身不脱敏。

旧原型保存限同一浏览器、同一来源地址，其导出格式与原生任务不同。导入旧草案时，不支持的字段须显式处理，原全局观察仅作未验证备注。新版本不继承旧观察的通过状态。

## 识别结果

保存成功、生成完成、文件内容一致、反馈覆盖、给定证据覆盖、Word 视觉和人的业务验收各自需要证据。`HOLD` 与失败不会因导出而清除。待定、冲突、缺观察、错层、过期或实际缺陷必须在交接中可见。

## 当前边界

首版本地界面支持一个主要需求、一个规则和 1–20 条检查，保留有限集合与单表单。账号权限、业务数据库、多人在线协作、真实审批、任意应用生成、任意 HTML/Word 双向合并、自动业务验收及生产部署继续独立评估。

既有准确公开来源资格沿用；本地候选新增源码、说明及合成材料在冻结后集中列单。当前不新增开源许可证、Pages、Release 附件或其他私有资产。
