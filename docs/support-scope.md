# 支持范围：公开 v1.0 与工作台交互原型

2026-10-28。公开 v1.0 基线为提交 `a81e9ad81c6ab0d133f29315ce6973b99845ffb3`。工作台为浏览器交互原型，未接入实际生成器，没有提供在线托管或桌面安装包。

## 按任务看能力

| 能力 | 已公开 v1.0 | 本轮工作台交互原型 |
|---|---|---|
| 需求与范围 | 六工作包、任务输入合同、来源与待定项 | 可视化填写背景、范围及字段，保存浏览器草案 |
| 原型类型 | 有限集合；本地单表单与有限状态流 | 选择这两类场景并编辑字段；预览属于交互草案 |
| 原型、PRD 与 Word | 给定同任务源材料，通过本地 Python CLI 单向生成 | 不执行 CLI、不生成 DOCX；导出不冒充正式交付物 |
| 修改和版本 | 既有 CLI 绑定前后输入并生成给定关系核对 | 保存首版快照、编辑修订、显示差异与反馈去向 |
| 检查与交接 | 汇总调用者给定的实际观察；未执行或错版保持待补充 | 初始检查未执行；可记录人工观察并导出交接草案 |
| AI 辅助 | 六项文字 Skill 的准确树与指定宿主显式供料已验证 | 原型不调用模型、不安装 Skill、不修改宿主配置 |
| 保存 | CLI 使用新目录，旧示例的页面操作多为当前会话 | 显式保存到当前浏览器；可导出、导入原型草案 |

## 保存与材料处理

本轮原型的保存限于同一浏览器、同一来源地址的本地存储。浏览器清理数据、切换设备或来源地址可能使其不可用；需要可携带备份时导出草案文件。原型应明确提示保存成功或失败，导入失败不得覆盖已有草案。

本地生成器和交互原型会保留调用者输入，本身不脱敏。示例为全新人工合成材料。原型不配置账号、网络上传、遥测或外部模型；若使用自己的 AI 助手，材料处理与费用由该宿主决定。

## 识别交付状态

- **草案已创建：** 浏览器中已有任务材料，不代表 Python 已运行。
- **修订有记录：** 能看到变化和处理决定，不代表决定已经真实批准。
- **待补充或含未决项：** 缺材料、反馈待定/冲突、未执行检查或发现问题继续保留。
- **已记录观察：** 使用者填写了观察描述，不构成来源认证或真实运行证明。
- **交接草案已导出：** 导出文件包含当前材料与边界；不自动升级为正式验收完成。

## 当前边界

支持范围以有限集合、单表单状态演示、同任务单向生成和给定关系核对为核心。账号权限、业务数据库、多人在线协作、真实审批、任意应用生成、任意 HTML/Word 双向自由合并、自动执行业务验收及生产部署需要分别设计和验证。

公开展示资格沿用已确认的准确范围。新增工作台文件、文案与合成材料按准确清单集中列出；使用许可、在线托管和发布附件另行说明。当前没有新增开源许可证。
