ABOUT THIS PROTOTYPE

先体验一条完整的工作路径。

这是独立的浏览器交互草案，用来讨论「创建任务 → 修订 → 交接」是否顺手。

  • 内容只在当前页面与本浏览器留存中处理；不使用账号、云存储、模型或网络接口。
  • 保存依赖浏览器允许本地存储。同一浏览器的本地文件与其他地址可能无法共享草案；导出文件可另行留存。
  • 导出的 JSON 是此原型自己的草案格式，不能直接作为现有 pm_task 的输入。
  • 首版快照保留，差异由本页面的字段比较得出；这不是现有命令行工具的精确审计结果。
  • Markdown 是文字交接草案，不是实际 DOCX。观察由人填写，不认证真实检查、审批或业务效果。
  • 导出文件含 prototype_demo 和 not_runtime_verified 标记。样例全部为新建人工合成材料。

格式：pm-toolkit-workbench-draft · 版本 1.0
导入上限 256 KB；字段最多 16 个，反馈最多 30 条。
