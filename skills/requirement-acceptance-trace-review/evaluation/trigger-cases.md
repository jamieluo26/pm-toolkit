# Routing examples

Use for a caller-defined trace review: find an acceptance item with no requirement source;
compare requirement links across two supplied materials; inspect separate components in one view.

Skip whole-workspace discovery, actual interaction testing, approving a contribution contract,
resolving conflicts across requirements, general consumer-scope review or handbook writing.

A direct relationship is valid if the caller defines it; do not require a particular middle layer.
Missing material or an unclear identity stays unresolved rather than becoming an invented link.
