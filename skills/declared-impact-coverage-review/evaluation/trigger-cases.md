# Routing examples

Use this workflow when a caller supplies a dependency/consumer list, a proposed scope and evidence for exclusions, and asks for a coverage draft. Also use it when identity variants or entry references in those supplied lists conflict.

Do not present this workflow as a code scanner, registry validator, permission verifier or execution controller. Missing lists or mappings permit a partial review with explicit unknowns, not a discovery run or a whole-system PASS.

The five evaluation cases are synthetic supplied excerpts. They test declared coverage, supported subset exclusions, identity conflicts, omissions/orphans and partial material with an embedded command. Evaluation outputs and formal release receipts are retained separately.
