# When this preservation review fits

Use when supplied feedback removes or replaces a presentation carrier and the caller needs
to check what happens to the functions it hosts. Keep an evidenced scoped cancellation
distinct from a carrier disappearing, and a machine observation distinct from a decision.
Partial mappings produce partial findings and questions, not whole-product assurance.

This is not general meeting summarization, code capability discovery, automatic interface
repair, historical release analysis, acceptance testing or task synchronization. It does
not install a fixed facet/state system or grant permission to change the source artifacts.
