# Trigger examples

Use when a caller supplies acceptance conditions and observations and asks which independent
states or dimensions have evidence, whether literal-copy or numerical claims conflict, or
which scope gaps prevent a conclusion. Supplied excerpts can support a bounded draft.

Skip actual interaction testing, screenshot inspection without images, source discovery,
automatic approval or deployment, general requirement tracing, rule-version lineage,
meeting decisions and handbook compilation. Route those tasks separately when authorized.

Behavior success does not settle appearance. A visible violation of an explicit applicable
range is a finding; an unexplained difference from a static example remains uncertain.
