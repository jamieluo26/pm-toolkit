# 试用反馈：只需三条

先用一个[完整合成案例](../examples/skills/README.md)试一次。完成或卡住都可以反馈；没有实际试用时，请不要把预期当成体验结果。

## 复制下面三条

```text
1. 我试的案例：反馈意图 / 会议决定 / 影响范围 / 需求追踪 / 验收证据 / 产品手册
2. 我完成到：没找到开始入口 / 已取得完整调用 / 已得到AI回答 / 已核对结果
3. 我最希望改的一点：（如果很顺，也请写最有用的一个发现）

可选：我用的AI助手/模型：
可选：我是否愿意换成自己的获准材料再用：愿意 / 需要改进后再试 / 暂时不需要
```

不用写姓名、公司、联系方式，也不用附原始会议或项目内容。反馈聚焦步骤和问题概述。

## 怎样提交

- **有GitHub账号：**[打开试用反馈表](https://github.com/jamieluo26/pm-toolkit/issues/new?template=skill-trial.yml)。提交后是公开Issue，正文、账号和附件对其他人可见；只写你愿意公开的概述。新模板需随本轮候选发布后才会在远端生效。
- **不想公开或没有GitHub账号：**复制上面的三条，保存为本地文本；由邀请你试用的人接收。本文不指定邮箱或私聊账号，也不自动发送任何内容。

## 维护者怎样记录

每条真实反馈登记一个本地编号，记录案例、是否独立完成、卡住的步骤、建议和再次使用意向。无回复记为未采集；完整调用被打开或仓库被Star，都不等于试用完成。未经另行同意，不把个人反馈原文或截图加入公开案例。
