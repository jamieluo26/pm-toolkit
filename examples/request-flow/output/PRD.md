# 协作请求表

版本：v1
源文件 SHA-256：652c062648093dc09b4ffe8e1bab1a76133f55fc4836cdc5fd96a55a4595a919

结构化规格单向生成本原型、PRD与待执行检查计划；手工改制品不会回灌规格。
输入由调用者提供，来源、脱敏与真实适用性未经工具核验。所有状态只是本地演示，不证明真人审批或实际验收。

## 定位、痛点与价值

定位：用一张本地表单讨论协作内容与处理状态，不接入真实流程。
痛点：合成背景：请求内容与补充理由分散，交接时不易看清当前状态。
价值假设：价值假设：把内容、补充理由和状态放在一起，减少理解差异；尚无真实用户效果数据。

## 固定交互

单表单、必填/类型/允许值/数值范围检查、四状态与四种转换。草稿和待补充可编辑，已提交和已完成只读；终态不能继续转换。
退回补充必须填写理由。提交/重提必须满足必填。数据只在本页面会话中变化，刷新恢复给定初值与初始状态。
字段配置生成新规格JSON，不修改当前演示或同步PRD；下载新规格后需重新build/check。无后台、存储、账号、真实审批、任意条件引擎。

## 字段合同

|字段|名称|类型|必填|允许值|数值范围|
|---|---|---|---|---|---|
|request_title|请求标题|text|是||—|
|category|请求类型|choice|是|资料整理 / 界面验证 / 文档协作|—|
|effort_hours|预计投入（小时）|number|否||0 ～ 80|
|audiences|相关角色|tags|否|产品 / 设计 / 研发|—|
|description|内容说明|text|是||—|

text为最长1000字符的单行文本；number须有限且绝对值≤9007199254740991，另受声明minimum/maximum约束；choice与tags须在给定集合内。可选数值允许null、单选允许空字符串、标签允许空数组。

## 状态与转换

给定初始状态：草稿（只是输入声明）

|前状态|动作|后状态|
|---|---|---|
|草稿|提交|已提交|
|已提交|退回补充|待补充|
|待补充|重新提交|已提交|
|已提交|完成|已完成|

## 需求与检查声明

### r_fields · 按给定类型、必填与范围核对表单值。

- r_fields-c1：清空请求标题后提交被阻止，状态仍为草稿。
- r_fields-c2：超出0至80小时或非法选项的输入不能提交。
- r_fields-c3：可选数值留空仍可提交，有效数值零按零保留。
### r_states · 演示提交、退回补充、重提与完成的有限转换。

- r_states-c1：草稿提交后为已提交且字段只读。
- r_states-c2：退回缺理由被阻止；给出理由后进入待补充并可编辑。
- r_states-c3：待补充满足必填后可重提，已提交可完成，终态只读。
### r_session · 所有数据与状态变化只在本页面会话中保留。

- r_session-c1：刷新恢复这份规格的给定初值与草稿状态。
- r_session-c2：恢复源样例会清空会话记录并重新载入源状态，不是业务回退。
### r_configuration · 可填写字段配置并导出新版本规格。

- r_configuration-c1：调整字段名称、选项或数值范围后可生成新规格JSON。
- r_configuration-c2：新规格parent绑定当前源SHA且版本不同，当前演示仍保持原版本和SHA。
- r_configuration-c3：保存新JSON后build/check形成新的同源原型、PRD与待执行计划。

## 给定初值

调用者给定内容被保留，工具不作脱敏或来源认定。
